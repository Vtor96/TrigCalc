# Тригонометрический калькулятор (Android)

Android-приложение для вычисления тригонометрических и логарифмических функций с поддержкой режимов ввода в радианах и градусах.

## Функционал

- Вычисление: sin, cos, tg, ctg, ln (натуральный логарифм), lg (десятичный логарифм).
- Переключение режима ввода: радианы / градусы.
- Подстановка констант: π и e.
- Смена знака числа.
- Очистка полей ввода и вывода.
- Меню с выходом из приложения.

## Стек

- Java
- Android SDK (compileSdk 28, minSdk 26)
- Android Support Library (appcompat-v7, constraint-layout)
- Gradle 6.7.1 / AGP 4.2.1
- JUnit (unit- и инструментационные тесты)

## Как запустить

1. Откройте проект в Android Studio.
2. Подключите Android-устройство (API 26+) или запустите эмулятор.
3. Нажмите Run.

## Особенности реализации

- Режим радиан/градусов реализован через два взаимоисключающих CheckBox.
- Перевод градусов в радианы: `rad = (π / 180) × grad`.
- Котангенс вычисляется как `1 / tan(x)`.
- Константы π и e подставляются в поле ввода кнопками.
- Все вычисления выполняются через `java.lang.Math`.

## Тесты

В проекте есть заготовки:
- `ExampleUnitTest` — локальный unit-тест.
- `ExampleInstrumentedTest` — инструментационный тест контекста приложения.
